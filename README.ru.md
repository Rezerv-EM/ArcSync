# ArcSync

[English](README.md) | **Русский**

**Лаунчер игр и синхронизация сохранений для Windows.** Как Steam Cloud, только для
любых игр: лицензии из Steam, GOG, Epic и Microsoft Store, а также игры,
установленные вручную, — в одной библиотеке.

Своих серверов у программы нет. Сохранения уходят только в ту облачную папку, которую
вы указали сами: OneDrive, Google Drive, Яндекс.Диск, Dropbox, MEGA, Nextcloud,
Mail.ru — или любая другая папка, которая у вас уже синхронизируется.

## Что умеет

* **Защищает сохранения.** Находит папки сохранений игр, следит за изменениями и
  забирает копии в вашу облачную папку. После переустановки Windows или на другом
  компьютере возвращает их обратно — и раскладывает туда, куда игра их ждёт.
* **Показывает библиотеку игр.** Только те игры, которые реально лежат на диске.
  Лончеры, ускорители, эмуляторы и прочие программы в библиотеку не попадают.
* **Запускает игры** из карточки, считает наигранное время и помнит, когда игра
  запускалась в последний раз.
* **Хранит резервные копии.** Архив копий по каждой игре, восстановление одной
  кнопкой, журнал того, что и когда синхронизировалось.
* **Не мешает.** Живёт в трее, синхронизирует по событию (запуск и выход из игры,
  завершение работы Windows) и по расписанию. Сворачивается в трей, игры не тормозит.

## Установка

1. Скачайте установщик последней версии (**`ArcSync_Setup_<версия>.exe`**) со страницы
   [Releases](../../releases/latest) — это единственный нужный файл.
2. Запустите его. Windows покажет синее окно **SmartScreen** — это нормально для
   программ без платной цифровой подписи: нажмите **«Подробнее» → «Выполнить в любом
   случае»**. Как проверить, что файл не подменили, — в разделе
   [Проверка файла](#проверка-файла).
3. При первом запуске укажите облачную папку (или нажмите «Предложить папку» — ArcSync
   сам найдёт OneDrive/Google Drive/Яндекс.Диск на диске). Дальше можно играть.

Ставить .NET, Windows App SDK или что-то ещё **не нужно** — всё внутри установщика.

### Требования

* Windows 10 (сборка 19041 и новее) или Windows 11, **64 бита**.
* Права администратора: без них Windows не даёт записывать сохранения в защищённые
  папки («Документы», AppData). Установщик запросит их сам.
* Свободное место: около 160 МБ на диске.

## Как это устроено

* .NET 8 и WinUI 3, обычное приложение (не из Microsoft Store).
* Движок слежения работает в том же процессе, что и интерфейс, — отдельную службу
  ставить не нужно.
* Игра определяется **по содержимому папки**, а не по названию: в библиотеку попадает
  то, что действительно является игрой.
* Обложки, баннеры и описания берутся из открытых источников (Steam, Wikipedia,
  PCGamingWiki и других) и кэшируются на диске, чтобы не дёргать сеть каждый раз.
* Перед копированием проверяется, что файл действительно сохранение, а не кэш, лог или
  мод.

## Приватность

* **Телеметрии нет.** Программа не отправляет статистику, не содержит рекламы и не
  передаёт третьим лицам сведения о вас или вашем компьютере.
* Сохранения уходят **только** в вашу облачную папку. Собственного сервера у ArcSync нет.
* Данные программы (настройки, история, кэш) лежат на вашем компьютере в
  `%LOCALAPPDATA%\ArcSync`.
* Облачная папка никогда не чистится автоматически: программа только добавляет и
  обновляет свои копии. Чужое в облаке не трогается.
* В интернет программа обращается только за обложками и описаниями игр — и передаёт
  туда лишь название игры.

## Частые вопросы

**Куда попадают сохранения?**
В папку `ArcSync` внутри той облачной папки, которую вы выбрали. Её можно открыть из
программы кнопкой «Открыть облачную папку».

**Что будет, если удалить игру?**
Её копии останутся в «Резервных копиях» и в облаке. Синхронизация продолжает их
защищать, даже если сама игра удалена.

**Игра не нашлась. Что делать?**
Нажмите «Перескан» в тулбаре — новую игру можно поставить, не перезапуская программу.
Если игра стоит в необычном месте, добавьте её вручную: «+» в библиотеке.

**Можно ли синхронизировать лицензии Steam?**
У игр с лицензией своё облако (Steam Cloud, Epic, GOG), поэтому ArcSync их не трогает
и показывает отдельной секцией — так библиотека не засоряется дублями.

**Антивирус ругается. Почему?**
Установщик не подписан сертификатом (он платный), поэтому SmartScreen и некоторые
антивирусы предупреждают о «неизвестном издателе». Проверить файл можно по SHA-256 —
см. ниже.

## Проверка файла

Рядом с установщиком в релизе лежит `SHA256SUMS.txt`. Сравните:

```
certutil -hashfile ArcSync_Setup_<version>.exe SHA256
```

Хеш должен совпасть со строкой из `SHA256SUMS.txt`. Скачивайте ArcSync только со
страницы релизов этого репозитория: копия из другого места может быть изменена.
