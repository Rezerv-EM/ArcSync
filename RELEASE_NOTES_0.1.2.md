# ArcSync 0.1.2 — автозапуск, который не теряется

**Файл:** `ArcSync_Setup_0.1.2.exe`

## Что исправлено

1. **Автозапуск пропадал после правки системных часов.** Задача в планировщике создавалась
   так, что у триггера «при входе в Windows» граница запуска равнялась моменту создания.
   Если Windows потом исправляла время назад (синхронизация, сбитые часы, смена пояса),
   эта граница оказывалась **в будущем** — триггер молча не срабатывал, и после
   перезагрузки программа не запускалась, хотя задача в списке есть. Теперь задача
   ставится из XML с фиксированной границей 2000-01-01, то есть всегда в прошлом.
2. **Ноутбук от батареи.** В задаче оставались умолчания `schtasks`: «не запускать, если
   компьютер работает от батареи» и «останавливать при переходе на батарею». Теперь оба
   выключены — программа запускается и живёт от батареи тоже.
3. **Планировщик больше не убивает программу через 72 часа** (`ExecutionTimeLimit` = без
   ограничения): раньше долгоживущий процесс считался «зависшим» и завершался.
4. Из 0.1.1: галочка «Запускать вместе с Windows» в установщике действительно включает
   автозапуск, решение запоминается в настройках, иконка в трее создаётся первой,
   список игр строится в фоне, повторный запуск показывает уже открытое окно.

## Установка

1. Скачайте `ArcSync_Setup_0.1.2.exe` ниже и запустите — он обновит установленную копию.
2. Windows покажет **SmartScreen** («Windows защитила ваш компьютер») — это ожидаемо:
   установщик не подписан платным сертификатом. Нажмите **«Подробнее» → «Выполнить в
   любом случае»**.
3. Автозапуск, включённый ранее, сохранится. Проверить: **Настройки → Автозапуск**.

**Требования:** Windows 10 (сборка 19041+) или Windows 11, 64 бита.

## Проверка скачанного файла

```
certutil -hashfile ArcSync_Setup_0.1.2.exe SHA256
```

Хеш должен совпасть со строкой в `SHA256SUMS.txt` из этого релиза.

## Известные ограничения

* Установщик не подписан — SmartScreen будет предупреждать.
* Интерфейс пока на русском языке.
* Windows 11 прячет новые иконки в области скрытых значков (стрелка «^» у часов) — иконку
  ArcSync можно оттуда перетащить на панель.
