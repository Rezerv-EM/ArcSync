ArcSync — облачное сохранение сейвов игр для Windows

Синхронизация сохранений между компьютерами: копии уезжают в вашу облачную папку и возвращаются на любом ПК. Как Steam Cloud, только для любых игр.

Что делает программа

Защищает сохранения

Находит, где каждая игра хранит сейвы, следит за изменениями и складывает копии в вашу облачную папку. Прогресс не потеряется при переустановке Windows или поломке диска.

Переносит прогресс на другой компьютер

Поставили игру на новый ПК, указали ту же облачную папку — ArcSync вернёт сохранения туда, куда игра их ждёт.

Собирает библиотеку игр

Показывает игры, которые реально установлены: Steam, GOG, Epic, Microsoft Store и установленные вручную. Лончеры и эмуляторы в список не попадают.

Держит резервные копии

Архив копий по каждой игре, восстановление одной кнопкой и журнал: что, когда и куда синхронизировалось.

Работает с любым облаком

OneDrive, Google Drive, Яндекс.Диск, Dropbox, MEGA, Nextcloud, Mail.ru — или любая папка, которая у вас уже синхронизируется.

Не мешает играть

Живёт в трее и синхронизирует по событию: запуск игры, выход из игры, завершение работы Windows. Игры не тормозит.

Как это работает

  1. Скачайте установщик и запустите его. Windows покажет предупреждение SmartScreen — это обычное дело для программ без платной подписи: «Подробнее» → «Выполнить в любом случае».
  2. Укажите облачную папку (OneDrive, Google Drive, Яндекс.Диск — или нажмите «Предложить папку», и ArcSync найдёт её сам).
  3. Играйте. Сохранения копируются сами, без единого нажатия.

Приватность

Своих серверов нет

Сохранения уходят только в ту папку, которую выбрали вы. У программы нет облака и нет аккаунтов.

Телеметрии нет

Никакой статистики, рекламы и слежки. Данные программы лежат на вашем компьютере в %LOCALAPPDATA%\ArcSync.

Облако не чистится

ArcSync только добавляет и обновляет свои копии. Чужое в облачной папке не трогается и не удаляется.

Частые вопросы

Это как Steam Cloud? В чём разница?

Steam Cloud работает только с играми из Steam. ArcSync делает то же самое для любых игр: из Steam, GOG, Epic, Microsoft Store и установленных вручную. Игры с лицензией он не трогает — у них своё облако, они просто показываются отдельным списком.

Нужно ли что-то доустанавливать?

Нет. Внутри установщика уже есть всё необходимое, включая среду выполнения. Нужны только права администратора — без них Windows не даёт записывать сохранения в защищённые папки.

Куда попадают мои сохранения?

В папку ArcSync внутри вашей облачной папки. Её можно открыть прямо из программы кнопкой «Открыть облачную папку».

А если игра удалена?

Копии остаются в «Резервных копиях» и в облаке — синхронизация продолжает их защищать, даже если сама игра удалена.

Почему Windows ругается при установке?

Установщик не подписан платным сертификатом, поэтому SmartScreen предупреждает о «неизвестном издателе». Проверить файл можно по SHA-256: он указан рядом с установщиком на странице релиза.

Системные требования

Windows 10 (сборка 19041 и новее) или Windows 11 · 64 бита · около 160 МБ на диске · права администратора. Ставить .NET или что-то ещё не нужно.
